# 다음 플레이

게임 프로필·기록·할 일·로컬 자동저장·백업 복원

## 실행

`python -m http.server 8000`

## 테스트

`npm test` (Node.js 내장 러너)

## 배포 상태

코드 구현과 로컬 테스트 완료. 유료 전환 없이 구현·로컬 검증을 먼저 진행합니다. 공개 상업 배포는 별도 단계입니다.

## 개인정보

입력 내용과 파일을 서버로 보내지 않습니다. 광고·방문 분석·결제 미연결. 실제 이용 효용과 매출은 미검증입니다.

## 개발 이어가기

Node 24 이상에서 `npm run dev`. `npm test`는 전체 JavaScript 구문과 핵심 로직을 검사합니다.

다른 탭의 변경 감지 시 자동 덮어쓰기를 중단하고, 현재 내용 백업 후 최신 기록을 불러올 수 있습니다. 동시에 실행되는 모든 쓰기를 완전히 직렬화하는 기능은 아닙니다.
