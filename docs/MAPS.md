# 게임메모 지도 기능

기본 화면: 지도 + 표식·메모. 추가 탭: 기존 플레이 기록. 기존 localStorage 노트 형식/키는 보존합니다.

지도는 IndexedDB에 이미지와 표식으로 저장합니다. 개인 이미지는 PNG/JPEG/WebP 10MB/2,400만 픽셀 이하, 긴 변 4,000px 최적화. 지도 20개/표식 500개 제한. 위치 0~1 정규화, 종류/제목/메모/완료 상태, 좌표 편집, 필터, 확대/축소·스크롤, 지도별 JSON 백업/새 지도로 복원. 지도 백업과 플레이 기록 백업은 별도입니다. 서버 업로드/계정 동기화는 없습니다. 동시 변경은 IndexedDB 트랜잭션 내 revision 비교로 거절합니다.

기본 지도 3종: Wesnoth 세계 지도, The Mana World 001-1 지역 미니맵, Flare Ancient Temple 원본 background 레이어 기반 바닥 간략도(완전한 길찾기 지도 아님). 각 게임의 보물상자/보물지도/두루마리 이미지를 보물 표식에 사용하고 나머지는 자체 공통 기호를 사용합니다. /maps/credits.html에 출처·저작자·수정·라이선스 전문과 원본 경로를 제공합니다. 게임 파일 버전은 maps/sources.json에 기록합니다.

검증: JS 구문 및 지도 데이터/백업 검사 2개 + 기존 노트 3개 통과. 실기기 검증 제외. 사용자 이미지 파일 선택 및 지도 백업 파일 복원 UI의 전체 흐름은 별도 검증 필요.
