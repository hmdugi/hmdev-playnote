# 기본 게임 변경

GTA5·엘든 링·스타듀 밸리 게임 선택과 게임별 표식 이름을 제공합니다. 세 상용 게임 지도·공식 아이콘의 재배포 허용을 확인하지 못해 이미지를 포함하지 않습니다. 버튼은 사용자 이미지 선택으로 연결됩니다. 기본 지도 3개 탑재로 설명하지 않습니다.

기존 오픈소스 지도는 기본 목록에서 제외했으며 저장한 개인 지도와 메모를 삭제하지 않습니다. 이전 출처 표기는 maps/legacy-credits.html에 보존했습니다. 새로 가져온 지도에 게임 ID를 저장하여 표식 이름을 적용합니다. 플레이 기록 유지. 자동 테스트 5개 통과.
